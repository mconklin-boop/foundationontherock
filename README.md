# Foundation on the Rock Website

A nonprofit website for Foundation on the Rock, built with Next.js and React.

## Local setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Update before launch

- Replace placeholder donation links.
- Connect the contact form to the selected backend or form provider.
- Add approved nonprofit compliance, EIN, tax-deductibility, and charitable solicitation language.
- Update email and mailing address when final.
